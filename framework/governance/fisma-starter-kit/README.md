# FISMA Starter Kit Helpers

These helper documents support NCI's FISMA Starter Kit activities for RMF Steps 1 and 2: categorize the system and select controls.

They are not replacements for the official NCI templates. Use them to collect draft answers, evidence, and assumptions before completing the official forms stored under `reference/nci-fisma-starter-kit/`.

Official reference templates currently expected in this repository:

- `reference/nci-fisma-starter-kit/NIH FIPS 199 System Categorization Template (2).docx`
- `reference/nci-fisma-starter-kit/NCI Business Impact Analysis Template.docx`
- `reference/nci-fisma-starter-kit/HHS E-Authentication Template (2).pdf`
- `reference/nci-fisma-starter-kit/PIA-NIH_NCI_System_Acronym_With_Model_Language_v2.pdf`

Example completed references:

- `reference/nci-fisma-starter-kit/ERIE FIPS 199 Categorization Worksheet ATO 06-09-2026.docx`
- `reference/nci-fisma-starter-kit/ERIE NCI Business Impact Analysis 06-09-2026.docx`

## Use In Startup

For Cloud One generated applications, create an `ato/fisma-starter-kit/` folder in the generated app and populate draft versions of these helpers using known startup, registry, GitHub, and Cloud One deployment context.

For local-only apps, do not generate a FISMA Starter Kit by default unless the user asks for ATO preparation.
